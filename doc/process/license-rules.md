# Ferrugem Licensing Rules

The Ferrugem Kernel is primarily licensed under:

    GPL-2.0-only

Source files should include SPDX identifiers at the top of each file.

Example:

    // SPDX-License-Identifier: GPL-2.0-only

or

    // SPDX-License-Identifier: GPL-2.0-only WITH Ferrugem-syscall-note

Contributors agree that submitted code may be redistributed under the project's licensing terms.

Third-party code must retain its original copyright notices and license information.
